קוד סוכן ניטור (IncidentBridge Agent) לאתר שלך

הטמע 4 שורות קוד בראש האתר האמיתי כדי שכל קריסה תקפוץ מיידית על המסך

העתק את הקוד הבא והדבק אותו בתוך תגית ה-<head> או בראש קובץ ה-JavaScript הראשי של האתר שלך: 

<!-- IncidentBridge Pro Real-Time Crash Agent -->
<script>
  window.addEventListener('error', function(event) {
    const payload = {
      type: 'INCIDENT_BRIDGE_CRASH',
      title: event.message || 'Unhandled Client Exception',
      sourceUrl: window.location.href,
      stackTrace: event.error ? event.error.stack : (event.filename + ':' + event.lineno),
      severity: 'fatal',
      timestamp: new Date().toISOString()
    };
    if (window.BroadcastChannel) {
      new BroadcastChannel('incident_bridge_bus').postMessage(payload);
    }
  });
  window.addEventListener('unhandledrejection', function(event) {
    if (window.BroadcastChannel) {
      new BroadcastChannel('incident_bridge_bus').postMessage({
        type: 'INCIDENT_BRIDGE_CRASH',
        title: 'Promise Rejection: ' + (event.reason ? (event.reason.message || event.reason) : 'Unknown'),
        sourceUrl: window.location.href,
        severity: 'critical'
      });
    }
  });
</script>
כיצד זה פועל?

הקוד עושה שימוש ב-BroadcastChannel API חוצה-טאבים. ברגע שתתרחש שגיאת קוד, קריסת זיכרון או אי-תפיסת הבטחה (Promise) באתר האמיתי שלך, המערכת תזהה את האירוע מיד ותקפיץ את התראת המסך הרוחבית בלי קשר לטאב שבו אתה נמצא.
